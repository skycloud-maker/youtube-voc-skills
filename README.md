# youtube-voc-skills

유튜브 댓글에서 제품 개선 포인트(VoC)를 찾는 업무를 **Claude 스킬로 넘기기 위한** 저장소.
스킬만 받으면 같은 순서·같은 기준으로 같은 업무를 할 수 있게 하는 것이 목표다.

> 원본 저장소 `youtube-comment-analyzer` 는 그대로 두고, 여기에 **사본을 새 구조로** 쌓는다.
> 데이터(댓글 원문·결과 파일)는 넣지 않는다. 검증용 정답 사례만 가려서 둔다.

## 어디를 보면 되나

| 하려는 일 | 볼 폴더 |
|---|---|
| 역할별로 무엇을 하는지 | [`docs/ROLES.md`](docs/ROLES.md) |
| 기준서·어휘·검사 규칙 (원본 한 벌) | `plugin/shared/` |
| 역할별 스킬 | `plugin/skills/<스킬 이름>/` |
| 1차 분석 엔진 (동결본, 고치지 않음) | `plugin/engine/` |
| 대시보드 | `plugin/dashboard/` |
| 스킬을 낱개 `.skill` 로 꾸리기 | `tools/` → 결과는 `dist/` (손대지 않음) |
| 옛 도구와 결과가 같은지 시험 | `tests/` |
| 무엇을 왜 정했나 · 진행 상황 | `docs/decisions/` · [`docs/progress.md`](docs/progress.md) |

## 나눠 주는 방식 (둘 다)

1. **플러그인 하나** — 저장소를 마켓플레이스로 추가하면 스킬 전부와 공통 파일이 함께 온다.
2. **낱개 `.skill` 파일** — 역할 하나만 넘길 때. 공통 파일은 조립 도구가 복사해 넣고,
   원본과 다르면 검사가 실패한다.

## 지키는 것

- API 키 등 비밀값은 저장소에 넣지 않는다. 받는 사람 환경에서 읽는다.
- `plugin/engine/` 은 동결본(원본 커밋 `d78dc8c`)이다. 고치지 않는다.
- `dist/` 는 생성물이다. 손으로 고치지 않는다.
