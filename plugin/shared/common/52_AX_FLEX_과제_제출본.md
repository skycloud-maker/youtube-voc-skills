# ■ 페이지 B — 1. 과제 수행의 배경 및 과제 목표

## 1) 과제를 수행하게 된 배경

```
고객가치혁신팀은 신제품 출시 전후로 YouTube 리뷰 영상의 댓글을 읽고
고객이 무엇에 불만인지, 무엇을 좋아하는지를 정리해 왔습니다.

2026년 3월부터 이 작업을 자동화하려는 시도가 있었습니다.
다만 1차 시도는 분류 정확도가 실무에 쓸 수준에 못 미쳐,
7월 말 분석 엔진과 대시보드를 처음부터 다시 설계했습니다.
이번 과제는 그 재설계 이후의 결과입니다.

이번 대상은 영상 21편 · 댓글 1,540건입니다.
1차 분석 엔진(사내 구축)이 자동으로 분류를 시도했지만
주제가 붙은 것은 40%(559건)뿐이었고, 나머지 967건은 「미분류」로 남았습니다.

★ 그래서 결국 사람이 1,540건 전량을 다시 읽어야 했습니다.
  출시 직후 가장 바쁜 구간에 21시간이 그대로 들어갔습니다.
  (총괄 실측 — 30행 판정에 20~30분. 1,540건이면 21시간)
```

## 2) 개선하고 싶은 문제

```
① 커버리지  — 라벨이 40%밖에 안 붙어 개선 과제로 이어지지 않는다
② 검증 부담 — AI에게 한 번 더 시켜도 「이 답을 믿어도 되는지」를 알 수 없다
               결국 전량을 다시 봐야 한다면 자동화의 의미가 없다
③ 재사용성  — 사람이 내린 판단이 기록으로만 남고 다음 회차에 반영되지 않는다
               매번 같은 판단을 처음부터 다시 한다

★ ②가 핵심입니다.
  「AI가 얼마나 잘하나」가 아니라 「어디까지 믿고 어디부터 사람이 볼까」가
  풀리지 않으면, AI를 아무리 잘 써도 사람 몫은 줄지 않습니다.
```

## 3) AX 적용을 통해 달성하고자 하는 목표

```
목표 1   사람이 읽어야 하는 건수를 전량 → 15% 이하로 줄인다
         ▶ 달성  1,540건 → 188건 (12.2%)

목표 2   주제가 붙은 행을 늘려 개선 과제로 이어지게 한다
         ▶ 달성  559건(40.2%) → 1,185건(69.8%) · 미분류 0건

목표 3   「믿어도 되는 구간」을 근거를 대고 말할 수 있게 한다
         ▶ 달성  AI 둘 합의 구간 표본 검증 93% 정확
                 갈린 구간은 사람이 본다 — 구간별로 나눠 잰다

목표 4   사람의 판단이 다음 회차에 자동 반영되게 한다
         ▶ 달성  판정 규칙 11종 · 자동 검사 16종으로 심어 놓음
                 주제 12종 신설
```
