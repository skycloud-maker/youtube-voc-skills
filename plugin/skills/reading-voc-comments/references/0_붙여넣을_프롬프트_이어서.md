# ★ 이어서 판독 — 새 창에 붙여넣는 것 (Codex · Claude Code 공용)

> **언제 쓰나** — 판독자가 「full_NN 까지 했습니다」 하고 멈췄을 때.
> 새 창을 열고 아래 회색 칸을 **그대로** 붙여넣으십시오. 고칠 것 없습니다.
>
> ★ **회차 번호를 적을 필요가 없습니다.** 판독자가 스스로 셉니다.
>   어제까지는 사람이 「full_36 까지 했으니 37부터」 를 손으로 써 주었습니다.
>   그러다 한 번 겹쳐 돌았고, 한 번은 마지막인 줄 몰라 번들을 안 만들었습니다.

---

```
================== 여기부터 복사 ==================

앞 창에서 하던 2차 판독을 **이어서** 합니다. 처음부터 다시 하지 마십시오.

[0단계 — 어디까지 왔는지 스스로 센다. 사람에게 묻지 않는다]

  작업 폴더를 먼저 찾는다. 이 대화에 붙은 파일이 있는 폴더, 또는 그 아래에
  「스크립트」 와 「_판독패키지」 가 함께 있는 곳이 작업 폴더다.

  거기서 이것을 돌린다.

      python 스크립트\자가점검.py

  그 다음 두 수를 센다.

      해야 할 회차 = 회차배치\ 의 full_*_ids.txt 개수
      끝난 회차     = _판독패키지\_결과\ 의 판독결과_full_*.md 개수

  ★ 「끝난 회차」 를 셀 때, 판정 파일이 있어도 **번들 폴더가 없으면 안 끝난 것**이다.
    그 회차는 다시 한다.

[1단계 — 앞 10회차가 제대로 됐는지 먼저 본다]

      python 스크립트\성실성검사.py

  ★ 반려가 나오면 **그 회차만** 다시 한다. 전체를 다시 하지 않는다.
  ★ 반려가 없으면 바로 2단계로 간다. 사람에게 알리지 않는다.

  반려 까닭을 스스로 고칠 수 없으면(도구가 없다, 데이터가 깨졌다) 멈추고 알린다.
  「얕게 함」 으로 반려된 것은 스스로 고칠 수 있다 — 원문을 다시 읽고 다시 판정한다.

[2단계 — 다음 회차부터 이어서 한다]

  끝난 회차 다음 번호부터 시작한다. 판정 방법은 처음 프롬프트와 똑같다.
  ★ 판정 기준을 다시 물어보지 마라. _판독패키지\ 의 기준문서를 읽으면 된다.

  ★★ 원문을 화면에 찍지 마라. 읽고 판정만 한다.
     (원문이 대화에 쌓이면 막힌다. 실제로 세 번 막혔다.)

  ★ 시각은 그때그때 적는다. 회차를 마친 뒤 몰아서 적지 마라.

[3단계 — 언제 멈추나]

  ㉠ 10회차쯤 하면 스스로 멈추고 「full_NN 까지 했습니다」 라고만 알린다.
     ★ 이때 최종 번들을 만들지 마라. 아직 끝이 아니다.

  ㉡ 다만 **끝난 회차 = 해야 할 회차** 가 되면 그때는 멈추지 말고
     처음 프롬프트의 [출력 3] 마무리를 끝까지 한다.
     최종 번들과 보정요청.csv 까지 만들어야 끝이다.

     ★ 마무리를 한 뒤 보정요청.csv 의 수정 시각이 최종 번들보다
       빠르면 안 된다. 빠르면 보정요청을 다시 만든다.

================== 여기까지 복사 ==================
```

## 왜 이렇게 만들었나 — 실제로 겪은 것만 넣었습니다

| 겪은 것 | 넣은 대목 |
|---|---|
| 사람이 회차 번호를 손으로 써 주다 한 번 겹쳐 돌았다 | 0단계 — 스스로 센다 |
| 판정 파일은 있는데 번들이 없어 반쪽인 회차가 있었다 | 0단계 ★ |
| `full_51` 을 전체 반려로 읽고 53회차를 다시 하려 했다 | 1단계 ★ 그 회차만 |
| 반려가 없는데도 사람에게 물어 멈췄다 | 1단계 ★ 알리지 않는다 |
| 원문을 찍다 정책 필터에 세 번 막혔다 | 2단계 ★★ |
| 시각을 몰아 적어 0초·1초가 됐다 | 2단계 ★ |
| 마지막 창이 자기가 마지막인 줄 몰라 번들을 안 만들었다 | 3단계 ㉡ |
| 보정요청이 번들보다 6시간 오래된 채 남았다 (B, 08-23) | 3단계 ★ |
