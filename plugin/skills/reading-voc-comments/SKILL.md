# 2차 판독 (VoC 판독자)

★ **자료가 없으면 달라고 한다 — 사용자 폴더를 뒤지지 않는다.**
  바탕화면 · 문서 · 다운로드처럼 사람의 개인 폴더를 찾아보지 않는다. 어느 파일이 필요한지
  말하고 기다린다 (2026-10-20 실제 AI 시험에서 파일이 없을 때 그 세 폴더를 뒤졌다).

이 스킬은 **판독 폴더를 차리는 일**과 **원래 판독 프롬프트를 그대로 따르는 일** 둘뿐이다.
판독 절차 · 판단 기준 · 검사 · 하지 않는 것은 전부 원문 프롬프트에 있다. 여기서 다시 쓰지 않는다
(판독자 둘의 조건이 한 글자라도 달라지면 대조가 무너진다).

## 순서

1. **작업 폴더를 정한다.** 사람이 가리킨 폴더, 없으면 지금 폴더.
   판독자마다 폴더가 따로여야 한다 — 다른 판독자의 판정 파일이 보이는 폴더에서는 하지 않는다.

2. **폴더를 차린다.** 이 SKILL.md 가 있는 폴더를 `<스킬>` 이라 하면

       python <스킬>/scripts/판독폴더_차리기.py <작업 폴더>

   옛 판독 꾸러미를 푼 것과 같은 모양(스크립트\ · 판독패키지\ · 판독대상\ · 프롬프트\ …)이 된다.
   이미 있는 파일은 건드리지 않으므로 이어서 할 때 다시 돌려도 된다.
   「✗ 재료를 못 찾았습니다」 가 나오면 스킬이 온전하지 않은 것이다 — 멈추고 사람에게 알린다.

3. **최신 결정을 먼저 읽는다** — 차린 폴더의 `판독패키지/0_최신결정_먼저.md`.
   2판 3차 · 4차에서 정한 것 가운데 원래 기준서에 없거나 옛 문장으로 남은 것을 모았다 (sky 2026-09-22).
   **원래 기준서 · 프롬프트와 부딪히면 이 파일을 따른다.** 원래 기준서는 원문 그대로 두었다.
   그 파일 §8 대로 검사를 **직접 돌린다** — 1차 자료를 앉힌 뒤(원문 0단계 다음) `python 스크립트/최신결정_검사.py 영상`,
   번들을 낼 때 `python 스크립트/최신결정_검사.py 번들` (✗ 가 없어져 0 으로 끝나야 낸다 · 2 는 멈추고 알린다).

3-2. **글이 다른 이름으로 가리키는 자리를 본다** — 차린 폴더 `0_먼저_읽으십시오.md` 의
   「★ 글이 다른 이름으로 가리키는 자리」 절.
   기준 문서와 안내서는 **옛 저장소의 폴더 이름**으로 적혀 있다. 예를 들어 대장을
   `s9_group/topic_group_map.json` 으로 가리키는데 이 폴더에 있는 것은
   `대장/topic_group_map.json` 이다. 그 절에 **왼쪽(글이 말하는 자리) → 오른쪽(이 폴더의 자리)**
   가 적혀 있으니 **오른쪽을 연다.**
   ★ 2026-10-28 실제 판독에서 이것 때문에 반려 1건과 계약 위반 24행이 났다.
     기준 문서 원문은 고치지 않았다(원문 그대로 둔다) — 그래서 이 절을 읽어야 한다.
   ★ 그 절이 **없거나** 글이 가리키는 자리를 그 절에서도 못 찾으면 **짐작해서 고치지 않는다.**
     무엇을 못 찾았는지 적어서 넘긴다 (보정요청).

4. **원문 프롬프트를 연다** — `<스킬>/references/0_붙여넣을_프롬프트_도구형.md`
   「여기부터 복사」 와 「여기까지 복사」 사이가 판독 지시의 전부다.
   **처음부터 끝까지 읽고 그대로 따른다.** [작업 폴더] 는 2 에서 차린 폴더다.
   1차 결과 엑셀을 찾고 앉히는 일(0단계)도 그 안에 있다.

5. **이어서 할 때**(새 창 · 회차 중간에 멈춘 뒤) — 2 를 다시 돌리고 3 을 다시 읽고
   `<스킬>/references/0_붙여넣을_프롬프트_이어서.md` 의 지시를 따른다.

## 판독자 이름

판정 파일 이름의 `<판독자이름>` 은 자기 이름을 쓴다 — Claude Code 는 `claudecode`, Codex 는 `Codex`
(2판 실제 판독이 쓴 이름. 3차 준비 도구가 이 이름으로 「누가 만든 것인가」 를 읽는다).
