★★ **2026-11-04 — 내가 앞서 여기에 적은 설명이 틀렸다. 바로잡는다.**

틀리게 적은 것 — 「Claude Code 는 저장소를 직접 읽지 않고
`~/.claude/plugins/cache/…/<판>/` 의 **사본**을 띄운다. 그래서 다시 깔지 않으면 옛 사본이 뜬다.」

**사실** — `claude plugin install` 이 스스로 이렇게 말한다:
「*it loads in place from `C:\작업\youtube-voc-skills\plugin`, so edits there take effect at
the next session start or `/reload-plugins`*」.
즉 **폴더(directory) 꾸러미장은 저장소에서 바로 읽는다.** 캐시 폴더는 판마다 떠 두는
**기록용 사본**이고, 실제로 뜨는 것은 저장소다.

**그러니 이렇게 된다 —**

| 무엇을 바꿨나 | 무엇을 해야 하나 |
|---|---|
| `plugin/` 의 **내용**을 고쳤다 | **앱을 다시 열면 된다** (또는 `/reload-plugins`). 다시 깔 필요 없다 |
| **판 번호**를 올렸다 | `claude plugin update youtube-voc@youtube-voc-skills` — 번호는 기록에서만 바뀐다 |
| 꾸러미장 **자리**를 옮긴다 | 아래 세 줄 |

★ 꾸러미 **자리를 옮길 때** — 2026-11-04 에 이 순서로 됐다:

```
claude plugin marketplace remove youtube-voc-skills
claude plugin marketplace add "C:\작업\youtube-voc-skills" --scope user
claude plugin install youtube-voc@youtube-voc-skills
```

※ `marketplace remove` 는 **꾸러미도 같이 뺀다** (`claude plugin list` 에서 사라진다).
그래서 `install` 을 반드시 뒤에 붙인다. `enabledPlugins` 의 `youtube-voc@youtube-voc-skills` 는
꾸러미장 이름이 그대로라 다시 깔면 **켜진 채로** 돌아온다.

★ **판 번호를 겹치게 쓰지 않는다.** 캐시 폴더가 `cache/…/<판>/` 로 판 번호마다 생기고
