## 3. 1차는 다시 돌리지 않는다 — 왜

옛 댓글을 **다시 모을 수 없다.** 지워진 댓글이 있고 새로 달린 댓글도 있어서, 같은
검색어로 다시 모으면 **모수가 달라진다.** 그러면 「AI 판정이 같은가」 를 재는 것이
아니게 된다. 그래서 **2판의 1차 결과를 그대로 2차 입구에 앉히고** 거기서 돌린다.

| 앉힌 것 | 자리 | 크기 |
|---|---|---|
| 1차 번들 | `C:\voc_2판통째\1차\engine\outputs\voc_dashboard_60\2판통째\voc_dashboard_export_bundle (14).xlsx` | 행 **6,336** · 칸 74 · 영상 **65** · 시트 6 |
| 영상메타 | 같은 폴더의 `7_영상메타.csv` | 영상 **21개** |

★ 영상메타가 21개뿐인 것은 **옛 2판도 그랬다** — 꾸러미 견본과 `video_id` 21개가
  전부 같다(세어 확인했다). 2판을 그대로 재현하는 것이므로 **고치지 않는다.**

## 4. ★ 행이 늘어난다 — 「100%」 가 무엇을 뜻하는지

```
1차 입력   6,336 행
옛 최종    6,846 행      ← 510 행이 뒤에서 늘어난다
```

3차 **D 판정**(「둘 다 맞다 — 나눠야 한다」)과 4차 반영이 행을 **쪼갠다.**
그래서 **행까지 100% 같으려면 쪼개는 판단까지 같아야** 한다.
sky 가 미리 말한 그대로다 — 「100프로 맞는게 아니고 일부 데이터 좀 차이가 생길수는
있지만」. 그 차이가 **몇 % 인지**를 내는 것이 이 실행의 결과물이다.

대조 도구는 행이 달라도 센다 — `양쪽` · `옛에만` · `새에만` 과 묶음별 %
(`tools/옛판_결과대조.py`).

## 5. 깃발 — `--깨끗` 을 쓴다 (왜)

결정 0006 §6 — 「사내 자리는 내 컴퓨터보다 헐벗다 … 사내에 주기 전에 **깨끗한
자리에서 다시 돌려 보는 것이 순서다.**」 내 컴퓨터의 전역 작업규칙과 훅이
판독자 머리에 먼저 들어가면 「스킬만 줘도 되는가」 를 재는 것이 아니게 된다.
`--깨끗` = `--setting-sources "" --strict-mcp-config` (우리 스킬 6개는 그대로 보인다).
