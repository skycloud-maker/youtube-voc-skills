
최종본을 앉히려면 `--최종 <최종엑셀>` 을 붙인다. 뜬 뒤 `http://localhost:8511`.

2. **카드로 보여 줄 것을 표로 그렸다** — 영상(②) · 대표 문의(③) · 과제(④) 가 전부 카드인데 표로 만들었다.
3. **③④ 는 축 자체가 다르다** — 코드만 보고 짐작해 `topic`·`cej` 로 그렸다. 원본은
   `문의 유형` · `니즈 신호 유형` · `정렬 축 4종` 이다.
