## 무엇을 하려는가

지금은 **2차 판독자 둘 · 3차 감독자 둘**을 Claude 와 Codex 로 나눠 쓴다.
Ver2 는 그것을 **Claude 하나**로 돌리되, Codex 가 하던 역할을 Claude 가 대신하게 한다 —
한 창은 평소대로, 다른 한 창은 **Codex 의 분석 로직을 적은 지시문**으로 읽게 해서 교차검증을 남긴다.

## ★ 먼저 분명히 해 둘 것 — 목적은 「똑같이」 가 아니다

두 판독자가 똑같아지면 **교차검증이 사라진다.** 원하는 것은 **둘이 같이 틀리는 일이 적은 것**이다.
그래서 Ver2 의 합격 조건은 「지시문이 그럴듯한가」 가 아니라 **「같은 모델 둘이 같이 틀리는 비율이
Claude+Codex 짝만큼 낮은가」** 다.

## ⑤ 에서 **반드시 같이 재야 할 것** (2026-10-09 에 생긴 새 증거)

Ver1 작업 중 **모델이 달라서 드러난 일**이 실제로 있었다 —
1차 스킬 시험의 과제문이 틀렸는데(자리를 안 주고 「자리를 차렸는가」 를 채점),
**Codex 가 SKILL.md 를 더 정확히 따라** 「자리를 어디에 만들까요」 묻고 멈춰서 드러났다.
Claude 는 묻지 않고 그냥 차려 **우연히 통과**했다.

→ 이것은 「둘이 다르게 본다」 의 실물 사례다. ⑤ 는 **같이 틀린 비율**뿐 아니라
**「한쪽만 알아차린 것」 이 Ver2 에서도 남는지**를 같이 봐야 한다. 안 남으면 Ver2 는 교차검증을 잃은 것이다.
