# 무엇을 어떻게 쟀나

자료는 2026-09-21/22 판독자 조합 실험의 **살아 있는 번들 다섯 벌** 이다 —
`기준데이터/스킬시험/실험_claudeA · claudeB · claudeD · codexC · codexE`. 같은 240행, 같은 판독 스킬.

| 짝 | 무엇을 보려고 |
|---|---|
| claudeA · codexC | 다른 모델 (5b 전) |
| claudeB · codexC | 다른 모델 (5b 전) — 같은 Codex 를 다른 Claude 판독과 |
| claudeD · codexE | 다른 모델 (5b 뒤 · 규칙이 바뀐 스킬) |
| **claudeA · claudeB** | **같은 모델 대조군** |

★ 대조군이 핵심이다. 판독은 **같은 모델로 두 번 돌려도 갈린다.** 그 흔들림을 빼지 않으면
모델 차이를 셀 수 없다. 그래서 이 문서의 「모델 몫」 은 전부

```
모델 몫 = (다른 모델 쌍 둘의 갈림 평균) − (같은 모델 쌍의 갈림)
```

이다. 단위는 맞댄 조각 대비 %p.

맞댄 방법 — 원문(`source_id`) 하나씩 대고, **조각 수가 다르면 라벨을 맞대지 않는다**(맞댈 수 없다).
조각 수가 같으면 조각마다 판정을 대고, 갈림을 다섯 종류로 나눈다.

그 자리는 이미 [가1]·[라1] 과 검사 도구로 처리했다 — 지시문으로 더 할 일이 아니다.

★ 정본으로 채점하면 **어느 쪽도 더 맞지 않았다** — 라벨이 갈린 자리에서 A 6 : C 8, B 6 : C 7.
Codex 가 더 정확해서 쓸 만한 것이 아니라, **다르게 보기 때문에** 쓸 만하다.

# 4. 답 — 대략 절반이다

모델 몫을 「쏠린 칸」 과 「흩어진 칸」 으로 갈라 더한 것 (A·C 기준):

| 쏠림 눈금 | 글로 적을 수 있는 몫 | 못 적는 몫 | 비율 |
|---|---|---|---|
| 상위 3가지가 50% 이상 덮으면 | 157 | 102 | **61%** |
| 60% 이상 (기본) | 143 | 116 | **55%** |
| 70% 이상 | 115 | 145 | **44%** |

눈금은 내가 정한 것이라 셋을 같이 적는다. 어느 눈금으로 봐도 **44~61%** —
**모델 차이의 절반쯤은 글로 적을 수 있고, 절반쯤은 적을 수 없다.**

## 적을 수 있는 것 — Codex 의 결 (지시문 초안의 뼈대)

1. **근거(`topic_evidence`)를 짧게 자른다** — 갈린 217건 중 172건(79%)에서 Codex 가 더 짧다.
   5b 뒤에도 그대로다(64 : 25). **가장 크고 가장 안 닫힌 차이다.**
2. **자사 브랜드를 함부로 적지 않는다** — 자사 얘기가 아니면 `brand` 를 비우거나 채널로 돌린다. (이미 규칙으로 닫음)
3. **역할(`entity_role`)을 모르면 `unknown` 으로 둔다** (5b 전). 규칙이 바뀐 뒤에는 거꾸로 적극적으로 매긴다.
4. **필요 신호(`need_signal_flag`)를 더 자주 켠다** — 5b 전 N→Y 54 : Y→N 10. (5b 뒤에는 반반 — 닫혔다)
5. **조각을 더 잘게 나눈다** — 같은 240행에서 Codex 281 조각, Claude 256~258 조각. 모델 몫 +4.0%p.
6. **제외를 덜 한다** — `out_of_scope_product` → 빈칸 ×35.

## 적을 수 없는 것 — 읽는 결

`cej` · `need_signal_type` · `topic` · `rootcause_cause` · `rootcause_target` — 덮음 9~39%.
바뀜이 제각각이라 「이런 꼴은 이렇게」 로 묶이지 않는다. 이 몫은 **지시문으로 가져올 수 없고,
같은 모델 둘로 바꾸면 그만큼 교차검증이 얇아진다.**

# 5. 걸림 — 이 숫자를 믿을 범위

- **대조군이 한 쌍뿐이다** (claudeA · claudeB). 판독을 한 번씩만 돌렸으므로 대조군 자체가 흔들린다.
- 5b 뒤는 **쌍 하나(D·E)뿐이고 같은 시기의 같은 모델 대조군이 없다.** 그래서 5b 뒤 숫자에는 모델 몫을 못 낸다.
- `codexC` 번들은 파생 칸 8개가 없다 (`sentiment_dir` · `brand_display` · `cej_group` · `validity` ·
  `confidence_gate` · `review_queue` · `market_display` · `competitor_brand_display_tags`) — 그 칸은 맞대지 않았다.
- 정본은 채점용 눈금이지 정답률이 아니다. 그리고 [가1] 뒤로 제품군이 어긋난 영상 7개의 행은 채점하지 않았다.
- 「쏠림 60%」 눈금은 내가 정한 것이다. 44~61% 는 눈금에 따라 움직인다.
