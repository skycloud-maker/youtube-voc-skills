# 유튜브VoC분석내부화 Ver3 — 모델 단일화 (Claude 하나)

> sky 2026-10-09 — 「구독을 하나로 줄여야 할 경우를 Ver3 으로 구분해서 하나씩 구축」
>
> 갈래 `claude/ver2-ver3` (Ver2 와 한 갈래다 — Ver3 은 코드가 없고 설정 두 줄로 바뀐다).
> **지금은 열어만 둔다.** Ver2 가 먼저다.

## 언제 꺼내나

Codex 구독을 유지할 수 없게 될 때. 그때 Codex 가 하던 자리(판독자 B · 감독자 A)를 Claude 가 메워야 한다.

## 무엇이 어려운가 — 이미 재 봤다

[갈림 분석](../검토_코덱스로직/1_갈림_분석.md) (2026-10-07) — **모델 차이의 44~61% 만 글로 적을 수 있다.**

| | |
|---|---|
| 적을 수 있는 것 | 근거를 짧게 자름 · brand 를 비움 · entity_role unknown · need_signal 더 켬 · 조각을 더 잘게 · 제외를 덜 함 |
| 적을 수 없는 것 | `cej` · `need_signal_type` · `topic` · `rootcause_*` (상위 3가지가 9~39% 만 덮는다) |

★ 교차검증의 값어치는 「둘이 다르게 본다」 에 있다. 똑같아지면 사라진다.
그래서 합격 조건은 「지시문이 그럴듯한가」 가 아니라 **「같은 모델 둘이 같이 틀리는 비율이 Claude+Codex 짝만큼 낮은가」** 다.

## 지렛대 셋 (하나만 믿지 않는다)

1. **지시문** — Codex 에게 물어 받은 로직을 적는다 (44~61% 를 되살린다)
2. **다른 Claude 모델** — 예: Opus + Sonnet. 「하나의 엔진(Claude)」 은 지키면서 모델 바탕 차이가 **진짜로** 남는다
3. **읽는 조건을 다르게** — 보는 순서 · 맥락을 달리 준다. 아직 안 재 봤다

## 차례

| | 무엇 | 비용 |
|---|---|---|
| ① | 갈림 분석 — **끝** (2026-10-07) | 0 |
| ② | Codex 에게 **자기 산출물을 근거로** 묻고 지시문 초안을 받는다 | 0 (구독이 있을 때 미리 해 둘 것) |
| ③ | Codex 가 한 말을 **다시 번들에 대고** 맞는지 본다 | 0 |
| ④ | 두 번째 판독 지시문을 쓴다 — 적을 수 있는 것만 | 0 |
| ⑤ | 같은 240행으로 **같이 틀린 비율**을 잰다 | ≈ $20 (새로 돌릴 것은 한 번) |

★ ② 는 **Codex 구독이 있을 때 미리 해 두는 것이 좋다** — 구독이 끊기면 물어볼 수 없다.

## ⑤ 에서 반드시 같이 재야 할 것

2026-10-09 에 **모델이 달라서 드러난 일**이 실제로 있었다 — 1차 스킬 시험의 과제문이 틀렸는데
(자리를 안 주고 「자리를 차렸는가」 를 채점), **Codex 가 SKILL.md 를 더 정확히 따라** 묻고 멈춰서 드러났다.
Claude 는 묻지 않고 그냥 차려 **우연히 통과**했다.

→ ⑤ 는 「같이 틀린 비율」 뿐 아니라 **「한쪽만 알아차린 것」 이 Ver3 에서도 남는지**를 같이 봐야 한다.
안 남으면 교차검증을 잃은 것이다.

## Ver2 가 Ver3 을 돕는다

Ver2 를 한 판 돌릴 때마다 같은 행에 대한 **Claude 판독과 Codex 판독이 짝으로** 쌓인다 —
그것이 ②~④ 의 자료다. 그래서 Ver2 를 쓰는 것만으로 Ver3 준비가 된다.
