# 묻는 것 — 당신(Codex)이 그렇게 판독한 까닭과, 그것을 글로 옮긴 지시문

같은 폴더의 `근거묶음.md` 를 먼저 읽어 주십시오. **당신이 2026-09-21 에 실제로 낸 결과**에서 뽑은 것입니다.

## 왜 묻나

지금 이 업무는 2차 판독자를 **둘**(Claude Code · 당신) 두고, 서로 다르게 본 행을 3차 감독이 봅니다.
사정이 생겨 **한쪽만 쓰게 될 때**를 대비해, 당신이 하던 판독을 다른 AI 가 **같은 결로** 할 수 있게
글로 옮겨 두려고 합니다.

★ 목적은 「똑같이 흉내 내기」 가 아닙니다. 둘이 똑같아지면 교차검증이 사라집니다.
우리가 원하는 것은 **당신이 무엇을 보고 그렇게 갈랐는지** 를 아는 것입니다.

## 답해 주실 것 — 셋

### ① 까닭 (근거묶음의 1~6 번 각각에 대해)

각 항목마다 이렇게 답해 주십시오.

- **그런 경향이 있었다고 보십니까?** (예 / 아니오 / 부분적으로)
- 그렇다면 **무엇을 보고 그렇게 했습니까?** — 판독 프롬프트·기준서의 어느 대목을 그렇게 읽었는지,
  또는 그 문서에 없는데 당신이 스스로 세운 기준인지 **구분해서** 적어 주십시오.
- **모르겠으면 모르겠다고** 적어 주십시오. 지어낸 설명은 쓸모가 없습니다 —
  우리는 당신 답을 다시 그 번들에 대고 맞춰 볼 것입니다.

### ② 지시문 (다른 AI 가 읽고 따를 글)

위에서 「이런 기준으로 했다」 고 말한 것 가운데 **규칙으로 적을 수 있는 것만** 골라,
판독자가 읽고 그대로 따를 수 있는 **지시문**으로 써 주십시오.

- 각 규칙은 **언제 걸리는지(조건) + 그때 무엇을 하는지(행동)** 가 분명해야 합니다.
- 보기를 하나씩 붙여 주십시오 — 되도록 `근거묶음.md` 에 실린 실제 조각에서.
- **규칙으로 못 적는 것은 적지 마십시오.** 대신 「이것은 글로 적기 어렵다」 고 따로 적어 주십시오.
  억지로 적은 규칙은 다른 AI 를 엉뚱한 데로 끌고 갑니다.

### ③ 당신이 보기에 — 글로 옮기면 잃는 것

같은 모델 둘이 이 지시문을 들고 읽으면, 당신과 Claude 가 둘이 읽던 것에 견줘
**무엇이 남고 무엇이 사라질 것 같습니까?** 짐작이어도 좋으니 까닭과 함께 적어 주십시오.
