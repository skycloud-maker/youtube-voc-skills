- 반대로 **17칸이 멍청규칙을 크게 넘은 것은 쏠림으로 설명되지 않는다.** 그리고
  **[다5] 위반 275 → 0** 은 일치율과 **무관하게** 기준서에 맞는 쪽으로 간 것이다.

#### 두 질문을 갈라야 한다 — 이것이 이번에 배운 것이다

| 묻는 것 | 재는 잣대 | 지금 답 |
|---|---|---|
| (가) **옛 2판을 재현하나** | 일치율 · D 묶음 | claude 바탕이 더 재현한다 (순이득 +15,045칸 · D 0 → 803행) |
| (나) **분석이 맞나** | 멍청규칙 대비 · 근거율 · 기준서 위반 | 17칸은 맞는 쪽 · **7칸은 증거가 안 됨** · `brand` 는 세 쪽 다 틀린 자리 |

**(가) 와 (나) 는 다른 질문이고, 나는 (가) 의 숫자를 (나) 의 말로 보고했다.**
2판통째 과제 자체는 (가) 를 묻는 과제였지만(「skill 만 넣었을 때 이전과 같게 나오나」),
sky 가 쓰려는 것은 **새 제품 · 새 시점의 VoC** 이므로 결국 (나) 가 중요하다.

#### ★ 새로 나온 것 — `brand` 는 **세 쪽 다 틀린 칸**이다 (sky 가 정할 일 ⑤)

이번 점검에서 나온 것은 「claude 가 나쁘다」 가 아니라 **`brand` 칸 자체가 기준서대로
채워지지 않고 있다** 는 것이다 — 옛 2판 88.8% · claude 88.5% · codex 80.6% 가 근거 없다.
`reference_brand` 가 이미 LG 고정이므로, `brand` 를 LG 로 채우는 것은 **새 정보가 없는
칸을 하나 더 만드는 일**이다.

고치는 길은 「판독자를 바꾸는 것」 이 아니라 **기준에 근거 규칙을 넣는 것**이다 —
「원문(본문)에 브랜드 이름이 없으면 `brand` 는 N/A」. 이것은 R18 이 `entity_role` 에
이미 적용한 규칙을 `brand` 로 넓히는 것이다. **다만 이것은 데이터의 뜻을 바꾸는 일이므로
sky 가 정해야 한다** (8-17 ⑤).

#### 한 줄로

**「저 퍼센트가 분석 정확도냐」 — 아니다. 옛 2판과의 일치율이다.**
sky 가 걱정한 `brand` 의 LG 쏠림은 **실제로 있었고**(옛 2판 92.58% 가 LG · 근거 88.8% 없음),
그래서 **`brand +40.92%` 는 좋아진 증거에서 뺀다.**
그래도 **17칸은 멍청규칙을 크게 넘고**, **[다5] 위반은 275 → 0** 이다.
**바탕을 바꾸는 근거는 남아 있지만, 그 근거가 `brand` 는 아니다.**

## 3. 그래서 — 「완성본인가」 에 대한 답

| 물음 | 답 |
|---|---|
| 꾸러미 순서대로 끝까지 도나 | **그렇다.** 1차(앉힘) → 2차 둘 → 총괄검수 → 3차 준비 → 감독 둘 → 마무리 → 아웃풋1 → 4차. 사람이 창을 열거나 붙여넣은 적 **0번** |
| 산출물 모양이 2판과 같나 | **그렇다.** 칸 **89 = 89** · 옛칸만 0 · 새칸만 0 · 시트 구조 같음 |
| 도구가 2판과 같게 동작하나 | **옛 동작으로는 그렇다** (회귀 없음). 2.0.13 에서 **일부러 하나 바꿨다** — ㉠ 감독 판정을 판정 24칸에 옮긴다. 그래서 얼린 3차 기준과 **바이트가 같지 않다**(판정 23칸 · 최대 417행). 옛 동작은 `VOC_얼린기준_재현=1` 로 돌릴 수 있고, 얼린 기준은 덮어쓰지 않았다 → 5-1절 |
| 값이 2판과 같나 | **칸마다 49~100%** (2.0.13 · 같은 6,171행에서 잰 값 — 5절). 규칙이 분명한 칸 90~100% · 해석 칸 **49.9~62.7%** (2.0.12 에서는 46~59% 였다) · 자유서술은 애초에 낱말 일치를 기대할 수 없다 |
| 왜 값이 갈리나 | **최종 판정 24칸의 바탕이 codex 판독자**이고, 그 한 명이 두 번 돌릴 때 다르게 판정했다. claude 판독자는 `brand` 91.7% 로 꽤 맞았다. ㉠ 으로 **감독이 고른 쪽**이 24칸에 닿게 했지만(+1~3.5%), **바탕을 누구로 하나**가 더 큰 몫이다 — `brand` 46.6 → **92.4%** 가 걸려 있고 그것은 **sky 가 정할 것**이다 (5절 「안 한 것」) |
| 이 숫자가 정확도인가 | **아니다.** 옛 2판도 정답지가 아니다 (AI 판정 + 사람 손질). 이 숫자는 **「두 번 돌리면 같게 나오나」** 하나다 |
| 빠진 단계가 있나 | **① 수집 · ② 1차 분석 둘이다.** ① 은 옛 댓글이 지워져 모수가 달라지고, ② 는 **수집 자료가 남아 있지 않다**(879개 다 합쳐 14.1% · 4-1절). 둘 다 **「안 했다」 가 아니라 「자료가 없어 못 한다」** 다 |

★ 남은 빈 칸은 **② 1차 분석 재현** 하나다. 어림은 4절에 있다 —
  **돈은 $5 안**이고, 막는 것은 「그때 수집한 원본 댓글이 어디 있나」 다.

★ **2026-11-02 — 그 빈 칸의 절반은 「못 한다」 로 닫혔다.** 세어 확인했다 (4-1절) —
  옛 저장소 아홉 자리의 수집 꼴 파일 **879개를 다 합쳐도** 우리 1차 댓글의 **14.1%** 만

  그것은 **1차 전체의 재현이 아니다** (4-2절). 돌리는 데 돈이 들어 **sky 의 승인 자리**다.
