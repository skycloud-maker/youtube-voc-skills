## 3. 그래서 — 「완성본인가」 에 대한 답

| 물음 | 답 |
|---|---|
| 꾸러미 순서대로 끝까지 도나 | **그렇다.** 1차(앉힘) → 2차 둘 → 총괄검수 → 3차 준비 → 감독 둘 → 마무리 → 아웃풋1 → 4차. 사람이 창을 열거나 붙여넣은 적 **0번** |
| 산출물 모양이 2판과 같나 | **그렇다.** 칸 **89 = 89** · 옛칸만 0 · 새칸만 0 · 시트 구조 같음 |
| 도구가 2판과 같게 동작하나 | **그렇다.** 24칸 처리까지 옛것과 같다 (회귀 없음) |
| 값이 2판과 같나 | **칸마다 46~100%.** 규칙이 분명한 칸 90~100% · 해석 칸 46~59% · 자유서술은 애초에 낱말 일치를 기대할 수 없다 |
| 왜 값이 갈리나 | **최종 판정 24칸이 codex 판독자 한 명 것 그대로**이고, 그 한 명이 두 번 돌릴 때 다르게 판정했다. claude 판독자는 `brand` 91.7% 로 꽤 맞았다 |
| 이 숫자가 정확도인가 | **아니다.** 옛 2판도 정답지가 아니다 (AI 판정 + 사람 손질). 이 숫자는 **「두 번 돌리면 같게 나오나」** 하나다 |
