# 결정 0006 — 시험은 **순수하지 않았다.** 재는 자리를 만들고 깃발로 끈다

> sky 2026-10-27 — 「지금 여기서는 순수하게 skill 만으로 돌아가는지.. 아니면 이전에 꾸러미와
> 과거 경험을 활용해서 더 자세하게 돌릴지를 모르지 않나요? 그리고 결과적으로는...
> 사내 skill 화가 필요한데... 어떻게 하는게 나을지..」
>
> **몰랐다.** 재는 자리가 없었다. 그래서 쟀고, **순수하지 않았다.**
> 이 문서는 무엇이 섞였는지 · 무엇은 안 섞였는지 · 앞으로 어떻게 끄는지를 못 박는다.

## 1. 무엇이 섞여 있었나 — 쟀다

### ① 전역 작업규칙이 들어가 있었다 (claude 쪽)

시험은 `claude -p` 를 그냥 띄웠다. 그러면 아이는 **내 컴퓨터의 설정을 그대로 물려받는다.**
`~/.claude/CLAUDE.md` 는 `C:\작업\_공통_작업규칙\CLAUDE.md` 를 불러오게 되어 있으므로,
**공통 작업규칙 전문이 아이의 머리에 먼저 들어간 채로** 시험이 시작됐다.

자기 보고를 믿지 않고 **내용으로** 댔다 — 「당신에게 미리 주어진 지침 안에 이 말이 있습니까」 로 물었더니:

| 물은 것 | 그대로 띄웠을 때 | 깃발로 끄고 띄웠을 때 |
|---|---|---|
| 「옛 저장소는 변화 0 · 복사만 한다」 | 「**예비로 남긴 옛 저장소는 변화 0.**」 … 「**복사만** 한다 — 원본은 그대로 두고 읽어서 새 저장소에 사본을 만든다.」 | 없음 |
| 「축약 금지」 | 「**축약 금지** (sky 2026-09-18 「절대 앞으로 축약하지 마세요」)」 | 없음 |
| 「건드림 / 안 건드림 / 확인할 것」 | 「변경마다 먼저 세 줄을 적는다 — **건드림 / 안 건드림 / 확인할 것.**」 | 없음 |

**문장째로 옮겨 적었다.** 섞였다는 증거다.

### ② 내 훅이 돌았다

모든 claude 시험 기록의 **첫 사건이 `SessionStart` 훅**이다
(`{"subtype":"hook_started","hook_name":"SessionStart:startup"}`).
`guard_notouch` · `twin_warn` · `done_gate` 도 걸려 있는 설정 그대로였다.

### ③ 보인 것이 많았다

기록 첫 `init` 사건에 아이가 본 것이 그대로 적혀 있다 — 실측:

```
스킬 50개 (우리 것 6 + 남의 것 44) · 슬래시 명령 87개 · 플러그인 3개
MCP 2개 (claude.ai Claude Docs · claude.ai Google Drive)   ← 어떤 그릇에서
모델 claude-opus-5[1m] · permissionMode bypassPermissions · apiKeySource none(구독)
```

구글 드라이브까지 **채널이 열려 있었다.** 채점기는 그동안 **명령의 경로만** 봤으므로
MCP 로 밖을 보는 길은 아예 보지 않고 있었다.

## 2. 무엇은 섞이지 **않았나** — 이것도 쟀다

| 재 본 것 | 결과 |
|---|---|
| 우리 스킬 **밖의** 스킬을 썼나 | **0** — `Skill` 호출 32번이 **전부** `youtube-voc:*` 여섯 중 하나 |
| MCP · 웹 · 서브에이전트를 썼나 | **0번** (73그릇 전량) |
| 옛 꾸러미(`C:\codex`) · 이 저장소 · 옆 시험을 봤나 | 안 봤다 (허용목록 채점, 전량) |
| 자동 메모가 갔나 | **안 갔다** — 시험 자리가 새 경로라 메모 자리가 **빈 채로** 생겼다 |
| codex 쪽은 어땠나 | **이미 깨끗했다** — `~/.codex/AGENTS.md` 가 **0바이트**, 25그릇에서 쓴 것이 셸 · 메시지 · 파일바꿈 · 할일 **네 가지뿐** |

★ 즉 **「옛 꾸러미를 베꼈나」 는 아니다.** 섞인 것은 **내 컴퓨터의 작업규칙과 훅**이다.
그리고 **보인 것**과 **쓴 것**은 다르다 — 그래서 앞으로 둘을 갈라 본다.

## 3. 어떤 깃발이 듣나 — 한 턴씩 실제로 돌려 재 봤다

| 깃발 | 보인 스킬 | 우리 스킬 | 훅 | MCP | 전역 규칙 |
|---|---|---|---|---|---|
| (그대로) | 50 | 6 | **돌았다** | 때에 따라 2 | **들어갔다** |
| `--safe-mode` | 21 | **0** ← 쓸 수 없다 | 안 돌았다 | 0 | 없음 |
| `--setting-sources "" --strict-mcp-config` | 27 | **6** | 안 돌았다 | 0 | **없음** |

**셋째를 쓴다.** 남는 21개는 Claude Code 에 **원래 들어 있는** 스킬이라
받는 사람 컴퓨터에도 똑같이 있다 — 뺄 수 없고 뺄 이유도 없다.
`--safe-mode` 는 우리 플러그인의 스킬까지 꺼서 **시험 자체가 성립하지 않는다.**

## 4. 정한 것

1. **claude 를 띄우는 자리를 한 곳으로 모은다** — `스킬시험_돌리기.claude_명령()`.
   2026-10-27 까지 시험 돌리개 **여섯 곳**에 같은 줄이 박혀 있었다. 그래서 깃발 하나를
   더하려면 여섯 곳을 고쳐야 했고, 그래서 **하나도 안 들어가 있었다** (공통 규칙 6).
2. **깨끗한 깃발을 기본으로 싣는다** — `깨끗한깃발 = ("--setting-sources", "", "--strict-mcp-config")`.
3. **그릇 자신이 「어떻게 돌았나」 를 말한다** — `시험.json` 에 `깃발` 을 적는다.
4. **채점 항목을 둘 더한다** (시험 여섯 전부, `공통항목` 한 자리에서 정한다):
   - 「우리 스킬 밖의 것을 쓰지 않았다 (남의 스킬·MCP·웹·서브에이전트)」 — **쓴 것**을 본다
   - 「시험 자리가 깨끗했다 (내 훅·MCP·전역 규칙이 안 들어갔다)」 — **보인 것**을 본다
   「못 봄」 은 통과가 아니다 — `init` 사건을 못 찾으면 **실패**다.
5. **옛 그릇 73개는 고치지 않는다.** 채점표는 동결이다. 대신 `tools/시험환경_보기.py` 로
   **읽어서** 말한다 — 지금 숫자는 **깨끗 25 / 73** (codex 25개가 깨끗, claude 48개가 물려받았다).

## 5. 재지 **않는** 것 — 영구히 못 본다

**모델이 학습으로 아는 것.** 끌 수도 셀 수도 없다. VoC 기준서는 공개 자료가 아니므로
영향이 작을 것이라고 보지만, **그것은 추론이고 재지 않았다.**

## 6. 사내 skill 화에 이것이 뜻하는 것

sky 2026-10-27 — 「사용자들이 어떤 AI 를 쓰고 있느냐에 따라 각 컴퓨터의 환경은 다릅니다.
우선 제 회사 컴퓨터에는 현재 **codex** 가 있고 동료 직원에게는 **claude** 가 있습니다.」

그래서 사내 자리는 **내 컴퓨터보다 헐벗다** — 전역 작업규칙도 훅도 없다.
지금까지의 시험은 **받는 사람 자리보다 후했다.** 사내에 주기 전에 깨끗한 자리에서
다시 돌려 보는 것이 순서다. 그 결과는 이 문서 아래에 덧붙인다.

★ 배포 모양도 **둘 다** 필요하다 — claude 쪽은 플러그인(`.claude-plugin/marketplace.json`),
codex 쪽은 `.agents/skills/`. 둘 다 이미 묶고 있다 (`tools/build_skills.py` · `tools/판_묶기.py`).
교차검증(판독 둘 · 감독 둘)은 **한 기계에 둘을 깔 수 없으면** 사람을 나눠 돌리는 모양이 된다 —
sky 자리(codex)와 동료 자리(claude). 그 길은 아직 밟아 보지 않았다.
