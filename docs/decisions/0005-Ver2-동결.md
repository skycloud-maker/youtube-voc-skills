## Ver2 가 무엇인가

Ver1 은 **단계마다 사람이 스킬을 부리는** 판이었다. Ver2 는 거기에 둘을 더한 판이다 —

1. **한 줄 돌리개** — 「인풋 1」 을 주면 1차 → 2차 판독 ×2 → 3차 감독 ×2 → 「아웃풋 1」 까지 가고,
   사람이 4차 결정을 채워 「인풋 2」 를 주면 반영 → 최종 엑셀 → 보고서(「아웃풋 2」)까지 간다.
   중간에 멈춰도 같은 명령으로 **이어서** 간다.
2. **여섯 번째 스킬 `showing-voc-dashboard`** — 최종 산출물로 **서버 없이 열리는 대시보드 HTML**
   한 장을 만든다. streamlit 대시보드의 다섯 화면을 **원본과 나란히 대고** 옮겼다.

| 역할 | 스킬 | 누가 돌리나 |
|---|---|---|
| 1차 실행 (수집 + 분석엔진) | `running-voc-engine` | Claude Code |
| 2차 판독 ×2 | `reading-voc-comments` | Claude Code · Codex |
| 3차 감독 ×2 | `supervising-voc-disagreements` | Codex · Claude Code |
| 차수 잇기 (2↔3 · 3↔4 · 4차 반영) + **한 줄 돌리개** | `coordinating-voc-pipeline` | Claude Code |
| 사내 보고서 | `building-voc-report` | Claude Code |
| **대시보드 HTML 한 장** | **`showing-voc-dashboard`** | Claude Code |

4차 검토는 **사람 몫**이다 (원래 그렇게 설계됐다).

## 무엇으로 「된다」 고 말하는가

- **기계 시험 216개** — 도구가 도는지. 전량 통과.
- **얼린 기준 20개 대조** — 2차 판독 · 3차 준비 · 3차 마무리가 **바이트까지 같다**
  (스킬이 차린 폴더에서 돌린 결과로 댔다).
- **한 줄 흐름이 실제로 끝에서 끝까지 돌았다** (`C:\voc_Ver2판1`) —
  인풋 1 → 아웃풋 1 → (사람 결정) → 인풋 2 → 아웃풋 2. 중간에 **세 번 멈추고** 같은 명령으로 이어갔다.
  4차에 **실제 사람 결정 683칸**을 넣어 돌렸고, 반영 확인이 **안 들어간 승인 17건을 잡아냈다**.
- **대시보드 다섯 화면을 원본과 나란히 대고 맞췄다** —
  원본(streamlit)을 로컬에 띄워 숫자·글귀·배지·칸 순서를 화면마다 댔다.
  자세한 대조는 [`docs/Ver2_한줄흐름/대시보드_대조표.md`](../Ver2_한줄흐름/대시보드_대조표.md).
- **그 대조를 기계가 지킨다** — `tests/test_대시보드html.py` 18개. 그중 일곱은 **엔진 원본 파일을
  그때그때 `ast` 로 읽어** 정렬 축 이름·정렬 칸·칸 **순서**·끼우는 자리·탭 순서·틀 글귀를 댄다.
  우리 쪽에 베낀 값이 아니라 원본을 읽으므로 **원본이 바뀌어도 · 우리가 빼먹어도 둘 다** 잡는다.
  전부 **일부러 깨 보고** 확인했다.
- **실제 AI 시험** — Ver1 때 다섯 스킬 전부 통과(결정 0003). 여섯 번째 스킬은 기계 시험과
  실제 번들로 확인했다.

## ★ 빈 칸 셋 — 무엇을 **못 쟀나**

「얼린 기준」 = 옛 도구가 어떤 입력으로 낸 결과 파일을 그대로 저장해 둔 것이다.
스킬에 같은 입력을 넣어 돌리고 **한 글자까지 같은지** 댄다.
2차·3차는 그렇게 재서 **같다**가 나왔다. 아래 셋은 그게 없다 — **셋이 서로 다른 물건이다.**

| 빈 칸 | 왜 비었나 | 잴 수 있나 |
|---|---|---|
| **1차** | 유튜브 댓글이 매일 달라지고, LLM 이 같은 글에도 매번 다르게 답한다 | **원리상 못 잰다.** 「돌아간다」 는 실제로 확인했다 (댓글 494개 → 조각 504개 · 66칸) |
| **보고서** | 옛 저장소에 보고서 산출물이 **하나도 없다** (0개). 섹션 8 에서 **새로 지은 것**이다 | **댈 상대가 없다.** 「기존과 같은가」 가 성립하지 않는다. 우리 출력을 얼려 **앞으로 안 변하는지**는 잴 수 있다 |
| **사람 결정이 든 4차** | 얼린 기준이 **사람 결정이 빈 상태**로 돈 것이다 | **잴 수 있다 — 이것이 진짜 빈 칸이다.** 아래 재료가 옛 저장소에 다 있다 |
